# CareBridge

CareBridge is a responsive nonprofit website concept built with React and Vite. It is designed as a standalone frontend project to demonstrate React fundamentals rather than as a personal portfolio.

## React concepts demonstrated
- Reusable components
- Props and array mapping
- Data-driven cards and sections
- State-based mobile navigation
- Responsive component layouts
- Semantic HTML and accessible controls
- Vite production build and Vercel deployment

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Vercel
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

All images are loaded from Unsplash for demonstration purposes. Replace them with approved local assets before using the website commercially.
